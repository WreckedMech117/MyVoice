# Story 4.1: Session Cleanup After Save

**Status:** In Progress
**Epic:** Epic 4: Resilience & Cleanup
**FRs Covered:** FR40

## Story Description

As a **user**,
I want to **have temporary files cleaned up automatically after I save a voice**,
So that **my disk doesn't fill up with preview files**.

## Acceptance Criteria

### AC1: Session Directory Creation
- **Given** the Voice Design Studio dialog opens
- **When** the dialog initializes
- **Then** a session directory is created at `voice_files/design_sessions/session_{uuid}/`

### AC2: Permanent Save Location
- **Given** I have generated 5 variations in a session
- **When** I save one of the variations
- **Then** the permanent embedding is saved to `voice_files/embeddings/{name}/`
- **And** the temporary session files remain (user might save another variant)

### AC3: Multiple Saves Allowed
- **Given** I saved variant 3 and want to also save variant 5
- **When** I save variant 5 with a different name
- **Then** both voices are saved to permanent storage
- **And** session cleanup happens only when dialog closes

### AC4: Session Cleanup on Close
- **Given** I have saved a voice and close the dialog
- **When** the dialog closes
- **Then** the session directory `voice_files/design_sessions/session_{uuid}/` is deleted
- **And** all temporary .pt and .wav files are removed

## Dev Agent Record

### Implementation Notes
- Session directory pattern: `voice_files/design_sessions/session_{uuid}/`
- Using UUID4 for unique session IDs
- Cleanup uses shutil.rmtree for recursive deletion
- SessionManager is a simple utility class in myvoice.utils
- Dialog exposes get_variant_output_path() for generation code to use
- Cleanup is idempotent (safe to call multiple times)

### Files Changed
- src/myvoice/utils/session_manager.py (new)

### Decisions Made

- Cleanup called from both _on_cancel_clicked and closeEvent for robustness
- is_cleaned property prevents duplicate cleanup attempts
