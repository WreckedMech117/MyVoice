## User Story
As a MyVoice user with accessibility needs, I want to use the application with keyboard only and screen reader, so that I can use MyVoice regardless of my physical abilities.

### Focus Style CSS
```css
/* Focus indicator */
*:focus {
    outline: 2px solid #0078d4;
    outline-offset: 2px;
}

/* High contrast focus */
@media (prefers-contrast: more) {
    *:focus {
        outline: 3px solid currentColor;
    }
}
```

### Accessible Names
```python
self.text_input.setAccessibleName("Text to speak")
self.generate_button.setAccessibleName("Generate speech")
```

### Live Region Announcements
```python
from PyQt6.QtGui import QAccessible

def announce_status(self, message: str):
    """Announce status for screen readers."""
    QAccessible.updateAccessibility(
        QAccessibleEvent(self.status_bar, QAccessible.Event.ValueChanged)
    )
```

## Technical Notes

### PyQt6 Accessibility Support
- Use `setAccessibleName()` for control labels
- Use `setAccessibleDescription()` for additional context
- Use `QAccessibleEvent` for live region announcements
- Set `Qt.WA_AccessibleWidget` attribute on custom widgets

### High Contrast Detection
- Check `QApplication.palette().window().color()` contrast
- Or use Windows API `SystemParametersInfo(SPI_GETHIGHCONTRAST)`
- Apply high contrast stylesheet when detected

### Focus Policy Settings
- `Qt.FocusPolicy.TabFocus` for keyboard-only focusable
- `Qt.FocusPolicy.StrongFocus` for keyboard + click focusable
- `Qt.FocusPolicy.NoFocus` for non-interactive elements
