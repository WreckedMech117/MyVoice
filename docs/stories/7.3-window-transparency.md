# Story 7.3: Window Transparency

## Status: Complete

## Story Overview
**Epic:** Epic 7 - Production Polish
**Story:** 7.3 - Window Transparency
**FR Coverage:** FR41

## User Story
As a MyVoice user, I want to adjust the window transparency so that I can see content behind the application while still having quick access to text-to-speech generation.

## Acceptance Criteria

### AC1: Transparency Slider in Settings
- [x] Settings → Interface tab contains a transparency slider
- [x] Slider range is 20% to 100%
- [x] Minimum 20% enforced (window never fully invisible)
- [x] Current value displayed as percentage label

### AC2: Real-Time Preview
- [x] As slider moves, window transparency updates immediately
- [x] No need to apply/save to see effect
- [x] Signal emits opacity value (0.2-1.0)

### AC3: Minimum Enforcement
- [x] Slider cannot be set below 20%
- [x] Values below 20% are clamped to 20% at runtime
- [x] Validation warns for stored values below 20%

### AC4: Persistence
- [x] Transparency setting persists between sessions
- [x] Value stored in AppSettings as window_transparency
- [x] Survives serialization round-trip

### AC5: Window Remains Interactive
- [x] Window responds to mouse events when transparent
- [x] Text input, buttons, and controls all function normally
- [x] No visual artifacts or rendering issues

## Technical Notes

### Opacity Value Conversion
- UI displays percentage (20-100)
- Internal storage uses opacity (0.2-1.0)
- Conversion: `opacity = percentage / 100.0`

### Qt Window Opacity
- `QMainWindow.setWindowOpacity(float)` sets transparency
- Range: 0.0 (fully transparent) to 1.0 (fully opaque)
- Window remains interactive at all opacity levels

### Signal Flow
1. User moves slider → `transparency_slider.valueChanged`
2. Handler updates label → `_on_transparency_changed`
3. Emits preview signal → `transparency_preview_requested(opacity)`
4. MainWindow applies → `_on_transparency_preview` → `set_window_transparency`
