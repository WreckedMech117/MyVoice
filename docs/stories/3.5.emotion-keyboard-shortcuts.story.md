## Technical Notes

### Implementation
The keyboard shortcuts are implemented in `MainWindow.keyPressEvent()` at `src/myvoice/ui/main_window.py:1061-1105`.

Key mapping:
```python
emotion_key_map = {
    Qt.Key.Key_F1: 0,  # Neutral
    Qt.Key.Key_F2: 1,  # Happy
    Qt.Key.Key_F3: 2,  # Sad
    Qt.Key.Key_F4: 3,  # Angry
    Qt.Key.Key_F5: 4,  # Flirtatious
}
```

### Window Scope Behavior
- Shortcuts are handled at the `QMainWindow` level
- `keyPressEvent` receives events even when child widgets (like text input) have focus
- Settings dialog is a separate window, so F1-F5 in dialogs don't trigger main window shortcuts
