# Story 5.2: Quick Speak Menu & Triggering

**Status:** Complete
**Epic:** Epic 5: Quick Communication
**FRs Covered:** FR34

## Story Description

As a **MyVoice user**,
I want **to quickly access my preset phrases via a popup menu**,
So that **I can generate speech with minimal interactions**.

## Acceptance Criteria

### AC1: Quick Speak Button
- **Given** the main window is displayed
- **When** the user sees the action button stack
- **Then** a Quick Speak button is visible in the stack
- **And** the button has a recognizable icon

### AC2: Popup Menu Display
- **Given** the user clicks the Quick Speak button
- **When** the menu appears
- **Then** all configured phrases are displayed in a popup menu
- **And** the menu appears below the button

### AC3: Single-Click Selection
- **Given** the popup menu is displayed with phrases
- **When** the user clicks on a phrase
- **Then** the phrase is selected immediately
- **And** TTS generation is triggered automatically
- **And** maximum 3 interactions: open menu, select phrase, auto-generate

### AC4: Keyboard Navigation
- **Given** the popup menu is displayed
- **When** the user presses arrow keys
- **Then** navigation moves between phrases
- **And** Enter/Return selects the highlighted phrase
- **And** Escape closes the menu

### AC5: Long Phrase Truncation
- **Given** a phrase exceeds 50 characters
- **When** displayed in the menu
- **Then** the text is truncated with ellipsis (...)
- **And** full text is shown in tooltip on hover

### AC6: Empty State
- **Given** no phrases are configured
- **When** the Quick Speak menu is opened
- **Then** "No phrases configured" message is shown
- **And** "Configure Phrases in Settings..." option is available

### AC7: Configure Navigation
- **Given** the user clicks "Configure Phrases..." in menu
- **When** the option is selected
- **Then** Settings dialog opens
- **And** Quick Speak tab is automatically selected

## Implementation Details

### Component: QuickSpeakMenu

Located at: `src/myvoice/ui/components/quick_speak_menu.py`

```python
class QuickSpeakMenu(QMenu):
    """
    Popup menu for Quick Speak phrase selection.

    Signals:
        phrase_selected: Emitted when user selects a phrase
        open_settings_requested: Emitted when user clicks configure
    """

    MAX_DISPLAY_CHARS = 50  # Truncation threshold
```

### Integration Points

1. **MainWindow**: Uses menu instead of dialog for quick access
2. **SettingsDialog**: `navigate_to_quick_speak()` method for direct tab navigation
3. **QuickSpeakService**: Shared service for entry management
