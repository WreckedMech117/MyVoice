# Story 7.4: Status Indicators

## Status: Complete

## Story Overview
**Epic:** Epic 7 - Production Polish
**Story:** 7.4 - Status Indicators
**FR Coverage:** FR42, FR43, FR44

## User Story
As a MyVoice user, I want to see the current status of TTS and virtual microphone so that I know if everything is working before I try to speak.

## Acceptance Criteria

### AC1: TTS Status Indicator Display
- [x] Status bar shows TTS indicator with emoji-based states
- [x] Green indicator (🟢 TTS) when TTS service is ready
- [x] Yellow indicator (🟡 TTS) when model is loading
- [x] Red indicator (🔴 TTS) when TTS service has error
- [x] Color + icon provides accessibility (not color-only)

### AC2: TTS Status Tooltips
- [x] Tooltip on hover: "TTS service ready" when green
- [x] Tooltip: "Loading voice model..." when yellow
- [x] Tooltip: "TTS service error: [message]" when red
- [x] Generate button disabled when TTS has error

### AC3: Virtual Mic Status Indicator Display
- [x] Status bar shows virtual mic indicator
- [x] Green indicator (🟢 Mic) when virtual mic connected
- [x] Warning indicator (⚠️ Mic) when not detected
- [x] App still functions when mic not detected (audio to monitor only)

### AC4: Virtual Mic Status Tooltips
- [x] Tooltip: "Virtual microphone connected: [device name]" when green
- [x] Tooltip: "Virtual microphone not detected. Click for setup help." when warning

### AC5: Virtual Mic Setup Guidance (FR44)
- [x] Clicking virtual mic warning indicator shows setup guidance
- [x] Guidance includes VB-Audio Cable setup instructions
- [x] Guidance includes Voicemeeter setup instructions
- [x] Links/instructions help user configure virtual microphone

### AC6: Generation Progress Indicator
- [x] Pulsing/animated indicator during generation
- [x] Indicator visible in status area during streaming
- [x] Indicator clears when generation completes

## Technical Notes

### Status Indicator Architecture
- ServiceStatusIndicator already supports colored dots
- Need to extend with emoji support for accessibility
- Pulsing uses QPropertyAnimation on opacity or size

### Virtual Mic Detection
- VirtualMicrophoneService.enumerate_virtual_devices() returns available devices
- Check app_settings.virtual_mic_device against available devices
- Show warning if configured device not found or no device configured

### Signal Flow
1. QwenTTSService/ModelRegistry emits state changes
2. App controller updates main_window.update_service_status()
3. ServiceStatusIndicator renders appropriate emoji/color
4. Click on warning triggers VirtualMicSetupDialog
