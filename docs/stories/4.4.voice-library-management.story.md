# Story 4.4: Voice Library Management

**Status:** In Review
**Epic:** Epic 4: Voice Creation
**FRs Covered:** FR19, FR46

## Story Description

As a **MyVoice user**,
I want **to manage my voice library by deleting voices I no longer need**,
So that **I can keep my voice collection organized**.

## Acceptance Criteria

### AC1: Voice List Display
- **Given** the user opens Voice Management in Settings
- **When** the voice list is displayed
- **Then** all voices are shown with their type icons
- **And** bundled voices show 📦 without delete option
- **And** user-created voices (🎭 designed, 🎤 cloned) show a delete button (🗑)

### AC2: Delete Confirmation
- **Given** the user clicks delete on a user-created voice
- **When** the delete action is triggered
- **Then** a confirmation dialog appears: "Delete '[voice name]' from your voice library? This cannot be undone."
- **And** Cancel and Delete buttons are shown

### AC3: Delete Execution
- **Given** the user confirms deletion
- **When** delete is executed
- **Then** the voice directory is removed from the filesystem
- **And** the voice is removed from the library list
- **And** if the deleted voice was selected, a bundled voice becomes selected

### AC4: Bundled Voice Protection
- **Given** the user attempts to delete a bundled voice
- **When** the UI is rendered
- **Then** no delete button is shown for bundled voices
- **And** bundled voices cannot be removed

### AC5: Empty State
- **Given** no user-created voices exist
- **When** the voice management section is displayed
- **Then** a helpful message appears: "Create your first voice"
- **And** prominent buttons for "Design from Description" and "Clone from Sample" are shown

### AC6: Voice Persistence
- **Given** voices are saved to the filesystem
- **When** the application restarts
- **Then** all user-created voices are loaded from `%LOCALAPPDATA%/MyVoice/voices/`
- **And** the voice library is restored (FR46 - voice library persistence)
