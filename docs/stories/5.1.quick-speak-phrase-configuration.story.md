# Story 5.1: Quick Speak Phrase Configuration

**Status:** Complete
**Epic:** Epic 5: Quick Communication
**FRs Covered:** FR33, FR47

## Story Description

As a **MyVoice user**,
I want **to configure my own preset phrases for quick access**,
So that **I can prepare common responses ahead of time**.

## Acceptance Criteria

### AC1: Quick Speak Tab in Settings
- **Given** the user opens Settings
- **When** the user navigates to the Quick Speak tab/section
- **Then** a list of configurable phrase slots is displayed
- **And** existing phrases are shown with edit capability
- **And** empty slots show placeholder: "Add a phrase..."

### AC2: Add New Phrase
- **Given** the Quick Speak configuration is displayed
- **When** the user clicks on an empty slot or "Add" button
- **Then** a text input field becomes active for that slot
- **And** the user can type a new phrase
- **And** the phrase is saved when the user confirms or moves focus

### AC3: Edit Existing Phrase
- **Given** the user has an existing phrase
- **When** the user clicks on the phrase
- **Then** the phrase becomes editable
- **And** the user can modify the text
- **And** changes are saved automatically

### AC4: Remove Phrase
- **Given** the user wants to remove a phrase
- **When** the user clears the text or clicks a remove button
- **Then** the phrase slot becomes empty
- **And** the slot is available for a new phrase

### AC5: Persistence
- **Given** phrases are configured
- **When** the user closes Settings
- **Then** all phrases are persisted to configuration (FR47)
- **And** phrases are available immediately in the main window

### AC6: Restore on Restart
- **Given** the application restarts
- **When** Quick Speak is accessed
- **Then** all previously configured phrases are restored
- **And** the order of phrases is preserved

### AC7: Empty State
- **Given** no phrases are configured
- **When** the Quick Speak menu is opened in the main window
- **Then** a helpful message appears: "No phrases configured"
- **And** a link or button opens Settings to configure phrases
