## User Story
As a MyVoice user, I want clear error messages with recovery guidance, so that I can fix problems without technical knowledge.

## Acceptance Criteria

### AC1: Error Message Pattern
- [x] All errors follow pattern: "[What happened] + [What to do]"
- [x] Technical jargon avoided
- [x] Tone is helpful, not alarming

### AC2: TTS Generation Errors
- [x] Message: "Speech generation failed. Please try again."
- [x] Retry option available when applicable

### AC3: Audio Device Errors
- [x] Message: "Audio device '[name]' is not available. Please select a different device in Settings."
- [ ] Link/button to open audio settings (future enhancement)

### AC4: Model Loading Errors
- [x] Message: "Not enough memory to load voice model. Try closing other applications and restart MyVoice."

### AC5: Voice File Errors
- [x] Message: "Could not load voice '[name]'. The voice file may be corrupted."
- [x] Suggestion: "Try recreating the voice or contact support."

### AC6: Application Stability (NFR6)
- [x] Application never crashes on errors
- [x] Other functionality remains usable after errors
- [x] Errors logged for debugging

### AC7: Critical Error Handling
- [x] Critical errors show modal dialog
- [x] User can copy error details for support
- [x] Application exits gracefully if necessary

### AC8: UI Responsiveness (NFR4)
- [x] All UI responses within 200ms
- [x] No freezing or hanging
- [x] Long operations show progress indicators

### Global Exception Handler
```python
def handle_exception(exc_type, exc_value, exc_traceback):
    # Log the error
    logging.error("Uncaught exception", exc_info=(exc_type, exc_value, exc_traceback))

    # Show user-friendly dialog
    if issubclass(exc_type, KeyboardInterrupt):
        sys.__excepthook__(exc_type, exc_value, exc_traceback)
        return

    # Show error dialog
    show_critical_error_dialog(exc_value)
```
