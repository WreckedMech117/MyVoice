# Story 7.1: Compact Always-On-Top Window

**Status:** Complete
**Epic:** Epic 7: Production Polish & Accessibility
**FR Coverage:** FR36, FR37

## User Story

As a **MyVoice user**,
I want **the application to display as a compact, always-on-top window**,
So that **it stays visible during gaming or voice chat without blocking my screen**.

### Implementation Pattern

1. **Window Setup** (`main_window.py:116-140`):
   ```python
   self.setWindowFlags(
       Qt.WindowType.FramelessWindowHint |
       Qt.WindowType.Window
   )
   self.resize(QSize(400, 188))
   ```

2. **Always-On-Top Toggle** (`main_window.py:1312-1369`):
   ```python
   def set_always_on_top(self, always_on_top: bool):
       base_flags = Qt.WindowType.FramelessWindowHint | Qt.WindowType.Window
       if always_on_top:
           new_flags = base_flags | Qt.WindowType.WindowStaysOnTopHint
       else:
           new_flags = base_flags
       self.setWindowFlags(new_flags)
   ```

3. **Settings Signal Chain**:
   - User toggles checkbox in Settings → Interface
   - `_save_current_settings()` updates `AppSettings.always_on_top`
   - `settings_changed` signal emits updated AppSettings
   - MainWindow's `_on_settings_changed()` calls `set_always_on_top()`
   - Window flags updated immediately
