# Story 6.3: Configuration Data Persistence

**Status:** Complete
**Epic:** Epic 6: Settings & Configuration
**FRs Covered:** FR46, FR47

## Story Description

As a **MyVoice user**,
I want **my voice library and Quick Speak phrases to be automatically loaded and persisted**,
So that **I don't lose my voice configurations and preset phrases between sessions**.

## Acceptance Criteria

### AC1: Voice Library Loading on Startup
- **Given** voice files exist in the voice directory
- **When** the application starts
- **Then** all valid voice files are loaded into the voice library
- **And** voice profiles are cached for fast subsequent loading

### AC2: Voice Directory Structure
- **Given** voice files are stored in the configured directory
- **When** the application scans for voices
- **Then** WAV files are detected and validated
- **And** accompanying .txt files are used for transcription

### AC3: Quick Speak Persistence
- **Given** the user has configured Quick Speak phrases
- **When** the phrases are saved
- **Then** they persist in CSV files in the config directory
- **And** multiple profiles can be managed (default, custom)

### AC4: Skip Corrupted Voices
- **Given** a voice file is corrupted or invalid
- **When** the application loads the voice library
- **Then** corrupted files are skipped with a log warning
- **And** the application continues loading other voices

### AC5: Fallback to Bundled Voice
- **Given** the selected voice is deleted externally
- **When** the application attempts to restore voice selection
- **Then** it detects the missing voice
- **And** automatically selects the default bundled voice (Sarira-F)
- **And** if default bundled is missing, selects first available voice

### AC6: Voice Selection Recovery
- **Given** no voice was previously selected
- **When** the application starts
- **Then** the default bundled voice is selected
- **And** the selection is persisted to settings

## Implementation Details

### Voice Fallback Mechanism (FR47)

Enhanced `restore_voice_selection` in ConfigurationManager:

```python
async def restore_voice_selection(self) -> Optional[str]:
    """Restore voice selection with fallback to bundled voice."""
    # Check if selected profile exists
    if not voice_exists:
        return await self._select_default_bundled_voice()
    return selected_profile

async def _select_default_bundled_voice(self) -> Optional[str]:
    """Select default bundled voice as fallback (Story 6.3: FR47)."""
    default_bundled = "Sarira-F"
    if default_voice_file.exists():
        await self.update_voice_selection(default_bundled)
        return default_bundled
    # Try first available voice if default missing
    wav_files = list(voice_files_path.glob("*.wav"))
    if wav_files:
        first_voice = wav_files[0].stem
        await self.update_voice_selection(first_voice)
        return first_voice
    return None
```

### Error Recovery Flow

```

    │
    ├─ Voice exists? ─────────► Return selected voice
    │
    └─ Voice missing ──────────► _select_default_bundled_voice()
                                     │
```
