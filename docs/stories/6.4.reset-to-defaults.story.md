# Story 6.4: Reset to Defaults

**Status:** Complete
**Epic:** Epic 6: Settings & Configuration
**FRs Covered:** FR48

## Story Description

As a **MyVoice user**,
I want **a way to reset all settings to their default values**,
So that **I can easily recover from misconfiguration or start fresh**.

## Acceptance Criteria

### AC1: Reset Button Location
- **Given** the settings dialog is open
- **When** the user views the Interface section
- **Then** a "Reset to Defaults" button is visible

### AC2: Confirmation Dialog
- **Given** the user clicks "Reset to Defaults"
- **When** the confirmation dialog appears
- **Then** it clearly explains what will be reset
- **And** has a checkbox option to also clear Quick Speak phrases
- **And** mentions that voice files will NOT be deleted

### AC3: Audio Device Reset
- **Given** the user confirms the reset
- **When** the reset completes
- **Then** monitor device is set to system default
- **And** virtual microphone is disabled (None)

### AC4: Voice Reset
- **Given** the user confirms the reset
- **When** the reset completes
- **Then** selected voice is set to default bundled (Sarira-F)
- **And** user's custom voice files are NOT deleted

### AC5: Window Settings Reset
- **Given** the user confirms the reset
- **When** the reset completes
- **Then** window position is cleared (will center on next launch)
- **And** always_on_top is set to true
- **And** transparency is set to 100% (fully opaque)

### AC6: Quick Speak Reset (Optional)
- **Given** the user checks "Also clear Quick Speak phrases"
- **When** the reset completes
- **Then** Quick Speak entries are reset to default samples
- **And** the default profile is recreated

### AC7: Theme and Advanced Reset
- **Given** the user confirms the reset
- **When** the reset completes
- **Then** theme is set to "dark"
- **And** log level is set to "INFO"

### AC8: UI Updates After Reset
- **Given** the reset completes
- **When** the settings dialog updates
- **Then** all UI controls reflect the default values
- **And** a success message is displayed

## Implementation Details

### Reset Button (Already Exists)

The "Reset to Defaults" button is located in the button area at the bottom of the settings dialog, alongside OK, Cancel, and Test buttons.

### Enhanced Reset Handler

```python
def _on_reset_defaults(self):
    """Handle reset to defaults button click (Story 6.4: FR48)."""
    # Show confirmation dialog with checkbox for Quick Speak
    msg = QMessageBox(self)
    msg.setInformativeText(
        "This will reset:\n"
        "• Audio devices to system default\n"
        "• Voice to default bundled voice\n"
        "• Window position (will be centered)\n"
        "• Always on top: enabled\n"
        "• Transparency: 100%\n\n"
        "Note: Your voice files will NOT be deleted."
    )

    checkbox = QCheckBox("Also clear Quick Speak phrases")
    msg.setCheckBox(checkbox)

    if confirmed:
        self.current_settings.reset_to_defaults()
        self.current_settings.selected_voice_profile = "Sarira-F"

        if checkbox.isChecked():
            self._reset_quick_speak_entries()
```

### Quick Speak Reset Helper

```python
def _reset_quick_speak_entries(self):
    """Reset Quick Speak entries to defaults (Story 6.4)."""
    self.quick_speak_service._create_default_profile()
    self.quick_speak_service.load_entries()
    self.quick_speak_widget.refresh_entries()
```

- Quick Speak reset is optional (checkbox) to avoid data loss
- Voice files directory not touched - only the settings change
- Window geometry cleared (None) rather than set to specific position

- Default bundled voice is "Sarira-F" (first alphabetically, well-tested)
