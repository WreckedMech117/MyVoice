# Story 6.1: Settings Panel Access

**Status:** Complete
**Epic:** Epic 6: Settings & Configuration
**FRs Covered:** FR40

## Story Description

As a **MyVoice user**,
I want **easy access to application settings through a dedicated button and keyboard shortcut**,
So that **I can configure the application without disrupting my workflow**.

## Acceptance Criteria

### AC1: Settings Button
- **Given** the main window is displayed
- **When** the user looks at the control area
- **Then** a Settings button with gear icon is visible
- **And** the button has tooltip "Open Settings (Ctrl+S)"

### AC2: Modal Dialog
- **Given** the user clicks the Settings button
- **When** the settings dialog opens
- **Then** it is a modal dialog (blocks main window interaction)
- **And** the dialog has a proper title "MyVoice Settings"

### AC3: Tabbed Interface
- **Given** the settings dialog is open
- **When** the user views the dialog
- **Then** a tabbed interface is displayed with tabs:
  - Audio
  - TTS
  - Interface
  - Quick Speak
  - Training (optional)

### AC4: Close with Escape
- **Given** the settings dialog is open
- **When** the user presses Escape key
- **Then** the dialog closes
- **And** settings are NOT saved (cancel behavior)

### AC5: Close with X Button
- **Given** the settings dialog is open
- **When** the user clicks the X button
- **Then** the dialog closes
- **And** settings are NOT saved (cancel behavior)

### AC6: Focus Returns to Text Input
- **Given** the settings dialog was open
- **When** the dialog closes (by any method)
- **Then** focus returns to the main window text input
- **And** user can immediately continue typing

### AC7: Ctrl+S Keyboard Shortcut
- **Given** the main window is active
- **When** the user presses Ctrl+S
- **Then** the settings dialog opens
- **And** this works regardless of focus position in main window
