# Story 4.2: Voice Design Dialog

**Status:** In Review
**Epic:** Epic 4: Voice Creation
**FRs Covered:** FR16, FR17, FR18, FR21

## Story Description

As a **MyVoice user**,
I want **to create a voice by describing it in text**,
So that **I can build character voices from my imagination without audio samples**.

## Acceptance Criteria

### AC1: Dialog Opening
- **Given** the user opens Voice Management in Settings
- **When** the user clicks "Design from Description"
- **Then** the Voice Design Dialog opens (450×350px modal)
- **And** focus moves to the description text field

### AC2: Dialog Layout
- **Given** the Voice Design Dialog is open
- **When** the user views the dialog
- **Then** a multi-line text field is displayed for voice description
- **And** placeholder text suggests: "Describe the voice (e.g., 'Elderly male, gravelly, Scottish accent')"
- **And** a Preview button is visible

### AC3: Preview Generation
- **Given** the user has entered a voice description
- **When** the user clicks Preview
- **Then** the VoiceDesign model is loaded if not already loaded
- **And** a loading indicator shows during model loading
- **And** sample text is generated with the described voice
- **And** audio plays through monitor speakers

### AC4: Preview Progress
- **Given** preview generation is in progress
- **When** the user waits
- **Then** a spinner or progress indicator is shown beside the Preview button
- **And** the Preview button is disabled during generation

### AC5: Save Options Display
- **Given** preview completes successfully
- **When** audio finishes playing
- **Then** the save options section appears
- **And** two radio buttons offer: "Prompt Voice" and "Clone Voice"
- **And** a name field appears for the voice name

### AC6: Prompt Voice Description
- **Given** the user selects "Prompt Voice" save type
- **When** the user reads the description
- **Then** explanation shows: "Text description stored. Voice regenerates dynamically (slight variation each time)."

### AC7: Clone Voice Description
- **Given** the user selects "Clone Voice" save type
- **When** the user reads the description
- **Then** explanation shows: "Audio from preview saved. Voice is consistent but uses cloning model."

### AC8: Save Voice
- **Given** the user enters a voice name and clicks Save
- **When** save is triggered
- **Then** the voice is added to the voice library under `%LOCALAPPDATA%/MyVoice/voices/designed/`
- **And** a success message confirms: "Voice saved: [name]"
- **And** the dialog closes
- **And** the new voice is selected in the main window dropdown

### AC9: Validation
- **Given** the description field is empty
- **When** the user attempts to click Preview
- **Then** the Preview button is disabled
- **And** validation message indicates text is required
