# Story 4.5: Model Lazy Loading for Voice Types

**Status:** In Review
**Epic:** Epic 4: Voice Creation
**NFRs Covered:** NFR11 (Memory Efficiency)

## Story Description

As a **MyVoice user**,
I want **the application to load voice models only when needed**,
So that **the app starts quickly and uses memory efficiently**.

## Acceptance Criteria

### AC1: Startup Loading
- **Given** the application starts
- **When** initial loading completes
- **Then** only the CustomVoice model is loaded (for bundled voices)
- **And** VoiceDesign and Base models remain in UNLOADED state
- **And** memory usage stays within limits (NFR11)

### AC2: Designed Voice Model Loading
- **Given** the user selects a designed voice (VoiceDesign type)
- **When** the voice requires the VoiceDesign model
- **Then** the ModelRegistry checks if VoiceDesign is loaded
- **And** if UNLOADED, triggers loading with progress feedback: "Loading voice model..."
- **And** state transitions: UNLOADED → LOADING → READY

### AC3: Voice Design Dialog Model Loading
- **Given** the user opens Voice Design dialog and clicks Preview
- **When** the VoiceDesign model is needed
- **Then** the model loads if not already loaded
- **And** user sees loading indicator in the dialog
- **And** preview proceeds after model is ready

### AC4: Cloned Voice Model Loading
- **Given** the user selects a cloned voice (Base model type)
- **When** the voice requires the Base model
- **Then** the ModelRegistry loads the Base model
- **And** the previously loaded model (CustomVoice or VoiceDesign) is unloaded first
- **And** only one model is loaded at a time (memory constraint)

### AC5: Model Switch Transition
- **Given** a model switch is required
- **When** the user changes voice types
- **Then** the current model unloads: READY → UNLOADING → UNLOADED
- **And** the new model loads: UNLOADED → LOADING → READY
- **And** brief loading feedback is shown (2-3 seconds typical)

### AC6: Same-Type Instant Switch
- **Given** the user switches between voices of the same model type
- **When** no model change is required
- **Then** the model remains loaded
- **And** voice switch is instant with no loading delay
