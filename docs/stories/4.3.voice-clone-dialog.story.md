# Story 4.3: Voice Clone Dialog

**Status:** In Review
**Epic:** Epic 4: Voice Creation
**FRs Covered:** FR13, FR14, FR15, FR20

## Story Description

As a **MyVoice user**,
I want **to clone a voice from an audio sample**,
So that **I can use a voice that sounds like me or someone specific**.

## Acceptance Criteria

### AC1: Dialog Opening
- **Given** the user opens Voice Management in Settings
- **When** the user clicks "Clone from Sample"
- **Then** the Voice Clone Dialog opens (450×380px modal)
- **And** an informational banner is displayed at the top (FR8a limitation warning)

### AC2: Info Banner
- **Given** the Voice Clone Dialog is open
- **When** the user views the informational banner
- **Then** the message reads: "Voice cloning preserves identity but does not support emotion control. For expressive speech, try Voice Design instead."
- **And** the banner is visually distinct (info style, not error)

### AC3: File Selection
- **Given** the dialog is open
- **When** the user views the file selection area
- **Then** a file path field and "Browse..." button are displayed
- **And** supported formats are indicated: WAV, MP3, M4A (NFR17)

### AC4: File Dialog Filter
- **Given** the user clicks Browse
- **When** the file dialog opens
- **Then** it filters to audio files: "Audio Files (*.wav *.mp3 *.m4a)"
- **And** the user can select an audio file

### AC5: File Validation
- **Given** the user selects an audio file
- **When** validation runs
- **Then** duration is checked (minimum 3 seconds required)
- **And** format is validated
- **And** results are displayed inline with ✓ or ✗ icons

### AC6: Duration Error
- **Given** the audio sample is less than 3 seconds
- **When** validation completes
- **Then** error displays: "✗ Sample too short (X.X seconds). Need at least 3 seconds of clear speech."
- **And** the Clone button remains disabled

### AC7: Validation Success
- **Given** the audio sample is 3+ seconds and valid format
- **When** validation completes
- **Then** success displays: "✓ Duration: X.X seconds" and "✓ Format: WAV"
- **And** the Clone Voice button is enabled (after transcription entered)

### AC8: Noise Warning
- **Given** background noise is detected in the sample
- **When** validation completes
- **Then** warning displays: "⚠ Background noise detected (quality may vary)"
- **And** cloning is still allowed (warning, not blocker)

### AC9: Clone Process
- **Given** the user clicks Clone Voice
- **When** cloning begins
- **Then** the Base model is loaded if not already loaded
- **And** a loading/processing indicator is shown
- **And** the sample is processed for voice cloning

### AC10: Preview Auto-Play
- **Given** cloning completes
- **When** the clone is ready
- **Then** a preview automatically plays using sample text
- **And** Play Preview and Replay buttons are available
- **And** a voice name field appears

### AC11: Save Voice
- **Given** the user is satisfied with the preview
- **When** the user enters a name and clicks Save Voice
- **Then** the voice is saved to `%LOCALAPPDATA%/MyVoice/voices/cloned/`
- **And** the source audio sample is stored with the voice
- **And** success message confirms save
- **And** the dialog closes and new voice is selected

## Dev Agent Record

### Implementation Notes
- Dialog follows existing pattern from VoiceDesignDialog
- Uses QwenTTSService.generate_voice_clone() for cloning
- Base model loaded lazily on first clone
- Source audio stored as source_sample.wav alongside cloned voice
- Audio validation uses soundfile for WAV, pydub for MP3/M4A

### Files Changed
- src/myvoice/ui/components/voice_clone_dialog.py (new)
- src/myvoice/ui/components/__init__.py (updated)
- docs/stories/4.3.voice-clone-dialog.story.md (new)

### Decisions Made
- Transcription required for quality cloning (ref_text parameter)
- Preview auto-plays using system default audio player
- Noise detection is a simple RMS-based heuristic (non-blocking warning)
- Source sample converted to WAV if originally MP3/M4A
